# 抽選最速適｜Random Field Selection (RFS)

RFS 是一個純前端土地清冊隨機抽選工具。網站將 Excel 讀取、彙整、抽選與結果匯出全部放在使用者瀏覽器中執行；清冊不會上傳到網站伺服器。

- 網站預定網址：https://chlinx.github.io/rfs/
- GitHub Repository：https://github.com/CHLINX/rfs
- 預設分支：main

## 功能

- 自動搜尋活頁簿所有工作表及標題列，不限定工作表名稱、標題列或欄位順序。
- 辨識欄位：流水號、土地座落地段、地號、本筆面積、契作面積（公頃）。
- 支援流水號、地段因合併儲存格而在後續資料列空白的情形。
- 排除小計、合計、總計列。
- 依「流水號＋土地座落地段＋地號」先行彙整；契作面積加總，本筆面積保留第一筆。
- 依設定的最低流水號數、每號土地上限及總抽選數，分批隨機抽選。
- 顯示抽選紀錄、抽選數量及唯一鍵／筆數／超抽檢核。
- 匯出 Excel，含深藍底白字標題、自動篩選、凍結首列及數值格式。
- 內建虛構範例，可直接試抽或下載範例清冊。

## 抽選規則

1. 先將唯一鍵相同的來源列合併，再以彙整後的土地紀錄作為抽選單位。
2. 第一批流水號不是先抽流水號清單，而是從尚未參與的土地中隨機抽出代表土地，以其流水號納入第一批，直到達到最低流水號數。
3. 第一批流水號全部形成後，才逐一抽選各流水號土地；每個流水號最多抽到個人上限或土地用盡。
4. 第一批完成且總數仍不足時，每次只新增一個尚未參與的流水號，再完成該流水號抽選。
5. 達到總抽選數即停止，不超抽。若所有可抽土地用盡仍不足，保留已抽結果並列示設定數、實際數及差額。
6. 匯出前檢查土地唯一鍵不重複、各流水號抽選數合計正確，且實際數不超過設定總數。

## 使用方式

1. 開啟網站，選擇或拖曳 Excel 清冊（.xlsx、.xls、.xlsm、.xlsb）。
2. 確認系統辨識的工作表、資料列數及彙整後土地數。
3. 設定最低流水號數、每個流水號最多抽選筆數及總抽選筆數。
4. 按「執行隨機抽選」，檢視抽選紀錄及結果。
5. 按「下載 Excel 結果」保存抽選結果。

必要欄位必須存在於同一個標題列。若來源面積欄使用公式，建議先以 Excel 開啟、重新計算並儲存，確保公式具有快取結果。

## 部署到 GitHub Pages

1. Repository 根目錄需有 `index.html`、`styles.css`、`app.js` 及 `.nojekyll`。
2. 開啟 Repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**。
5. 等待 GitHub Pages 完成部署，再開啟 https://chlinx.github.io/rfs/。

## 檔案

- `index.html`：網站頁面及說明內容。
- `styles.css`：桌面與手機版響應式樣式。
- `app.js`：Excel 欄位辨識、彙整、抽選及匯出。
- `.nojekyll`：GitHub Pages 靜態資源設定。

## 隱私與注意事項

網站不會將清冊送到網站後端；Excel 檔案只在目前瀏覽器分頁中處理。網站會從 CDN 載入 Excel 函式庫，首次使用需連線。仍請遵守機關資料管理規範，避免在公用或共用電腦處理含個資的正式清冊。
